# GRANDIA REBIRTH PROJECT

**あの冒険を、次の世代へ。**

1997年のRPG『グランディア』への愛と、未知へ踏み出す喜びを次世代につなぎたいという願いから始まった、非公式ファンの構想・交流サイトです。

This is an **unofficial fan initiative**, not affiliated with or endorsed by the rights holders. No remake is authorized, in production, or announced. Any future remake would require the appropriate permissions from rights holders.

## Development

```sh
npm install
npm run dev
npm run build
```

Built with Astro and TypeScript. Intended for static hosting on Vercel.

## Content and rights

Original game artwork, music, logos, characters, and other protected assets are **not** included in this repository. Site content and independently created artwork must be reviewed for rights before reuse. No license has yet been granted for reuse of this repository's content.
